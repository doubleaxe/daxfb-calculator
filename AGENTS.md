# AGENTS.md

## Purpose

This repository is a monorepo for a React-based rewrite of `daxfb-calculator`, a factory planner for management games.

## Environment

- Package manager: `pnpm@11.3.0`
- Workspace layout: `packages/**`
- Version control: `git`
- Code format: `prettier` and `eslint`

## Workspace Structure

- `packages/calculator-ui`: Vite application entrypoint and top-level routing.
- `packages/calculator-core`: Shared calculator runtime, stores, generic flowchart UI, toolbar, palette, and initialization.
- `packages/calculator-games/[game]`: Game integration layer, game context provider, and concrete app window composition.
- `packages/gamedata-generated`: Generated game data and sprite assets consumed by the UI. Do not modify unless explicitly asked.
- `packages/shared`: Shared TypeScript utility and gamedata types.
- `packages/calculator-styles`: Shared Panda CSS configuration and generated styled-system package exports, this is system autogenerated package, do not modify.
- `packages/calculator-core/src/game/model` is a model for UI, it keeps all links and positions, which are handled by `mobx` to update UI state.
- `packages/calculator-games/[game]/src/game/model`is a game specific model with game specific properties

## Libraries and technologies

- Code
    - `react`
    - `typescript`
    - `mobx` for state management
- UI
    - `mantine`
    - `phosphor-icons`
    - `dnd-kit` for drag-n-drop
    - `xyflow` for flowchart
- Styling
    - `mantine` when base styles are acceptable
    - `panda css` for customizations

## Commands

Run commands from the repository root unless package-local behavior is needed.

- Install dependencies: `pnpm install`
- Lint all workspaces: `pnpm lint`
- Format all workspaces: `pnpm format`
- Start the Vite app with Panda watch: `pnpm --filter @doubleaxe/daxfb-calculator dev`
- Type-check UI app: `pnpm --filter @doubleaxe/daxfb-calculator check`
- Type-check core package: `pnpm --filter @doubleaxe/daxfb-calculator-core check`
- Type-check COI package: `pnpm --filter @doubleaxe/daxfb-calculator-games.coi check`
- Type-check shared package: `pnpm --filter @doubleaxe/daxfb-shared check`
- Type-check generated data package: `pnpm --filter @doubleaxe/daxfb-gamedata-generated check`

## Editing Guidance

- Keep generic planner logic in `calculator-core`.
- Keep game-specific parsing, model assembly, and page wiring in `calculator-games/[game]`.
- Keep shared type-only helpers in `shared`.
- Follow the existing React style: function components, lazy loading at the app level, and `observer` where UI depends on MobX state.
- Preserve the current package boundaries instead of moving code into the app package unless it is truly app-shell specific.
- Use `className={hstack({})}` and `className={vstack({})}` for simple flexboxes.

## Verification Expectations

For code changes, prefer the smallest relevant verification set:

- run the relevant `check` command for the touched package(s)
- run the relevant `lint` command for the touched package(s)
- run the relevant `format` command for the touched package(s)
- eslint is slow, prefer to use `npx eslint --fix [list of changed liles]` from workspace root
