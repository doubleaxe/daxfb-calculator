# AGENTS.md

## Purpose

This repository is a monorepo for `daxfb-calculator`, a factory planner for management games. It is not simple automatic calculator - user writes complex factory graph, and it computes product flow using lineal algebra.

## Environment

- Package manager: `pnpm`
- Version control: `git`
- Code format: `prettier` and `eslint`

## Tools

- Prefer to use `rg` if available

## Workspace Structure

- `packages/calculator-ui`: Vite application entrypoint and top-level routing.
- `packages/calculator-core`: Shared calculator runtime, stores, generic flowchart UI, toolbar, palette, and initialization.
- `packages/calculator-games/[game]`: Game integration layer, game context provider, and concrete app window composition.
- `packages/gamedata-generated`: Generated game data and sprite assets consumed by the UI. Do not modify unless explicitly asked.
- `packages/shared`: Shared TypeScript utility and gamedata types.
- `packages/calculator-styles`: Shared Panda CSS configuration and generated styled-system package exports, this is system autogenerated package, do not modify.
- `packages/calculator-core/src/game/model` is a model for UI, it keeps all links and positions, which are used to update UI state.
- `packages/calculator-games/[game]/src/game/model`is a game specific model with game specific properties

## Commands

Prefer to lint/check only touched packages or even files.

- Install dependencies: `pnpm install`
- Lint: `pnpm lint` or `npx eslint --fix [list of changed liles]`
- Format: `pnpm format`
- Start the Vite app with Panda watch: `pnpm --filter @doubleaxe/daxfb-calculator dev`
- Type-check: `pnpm --filter @doubleaxe/[package] check`

## Editing Guidance

- Use panda helper `className={hstack({})}` and `className={vstack({})}` for simple flexboxes.

## Development workflow

Development is performed in pair programmer mode, human + AI. Do not do anything automatically, only after explicit request, even if change leads to not compiling code somewhere else. Files can be modified between requests - if file was changed - human did this, do not overwrite changes or restore previous version. Do not cross project boundary.

## Current status

Currently project is being migrated from react to vue. There are react leftovers everywhere, some files do not compile. Do not delete old react files.
